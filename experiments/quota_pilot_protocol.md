# German–Spanish quota pilot protocol

The primary question is whether smoothing an assumed German-to-Spanish inventory ratio of 9:1 improves prediction on an equally weighted bilingual test set. The inventory ratio defines the scenario. The experiment uses real sentences for training and testing.

- **Primary comparison.** A smoothed 75:25 character quota (allocator exponent 0.5) versus proportional sampling at 90:10 (exponent 1). Report a 50:50 condition (exponent 0) for context. Keep all three conditions and report each language separately.
- **Training.** Draw a fixed pool of 1,500 distinct NFC-normalized training sentences per language from the official German and Spanish GSD training splits in Universal Dependencies r2.15. Exclude normalized test matches. Give each tokenizer a 50,000-code-point budget, a 512-entry byte BPE vocabulary, and the same pre-tokenization. Use seeds 11, 29 and 47, paired across quotas. Record achieved shares.
- **Language model.** Fit a separate add-0.1 smoothed token bigram for each tokenizer on the same complete bilingual training pool. Predict from the previous token only. Start at BOS and include EOS in the predicted outcomes.
- **Evaluation.** Use the aligned German and Spanish PUD test sets (1,000 sentence pairs). Keep the entire test set out of fitting and model selection. For each sentence, sum the probabilities of all token paths of the bigram that decode to exactly its UTF-8 bytes and then terminate. Divide total negative log-base-two likelihood by the number of test bytes in each language. Report the corresponding byte perplexity, two raised to that rate. Score the canonical BPE path separately as a diagnostic.
- **Summary.** Compare models on the same sentences, give German and Spanish equal weight in bits per byte, and show the three paired runs. Report the change in perplexity as a percentage of the stated baseline. Lower values indicate better prediction under this metric.
- **Uncertainty.** As a sensitivity check, resample aligned PUD documents in pairs across languages and conditions. Keep the nine fitted models fixed. Report a percentile interval for the primary macro contrast along with the individual seed effects.

The outcome applies to a small bigram model evaluated on PUD. Task accuracy would require a separate labeled prediction task. The reference corpora are documented by Universal Dependencies: [German GSD](https://universaldependencies.org/treebanks/de_gsd/), [Spanish GSD](https://universaldependencies.org/treebanks/es_gsd/), [German PUD](https://universaldependencies.org/treebanks/de_pud/) and [Spanish PUD](https://universaldependencies.org/treebanks/es_pud/). For the distinction between a canonical token path and string likelihood, see [Cao and Rimell (2021)](https://aclanthology.org/2021.emnlp-main.161/).
